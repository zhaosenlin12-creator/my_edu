# 六轮直播 SOP（主战场）

> 六轮 SOP，每轮 5–15 分钟。

## 第 1 轮：信任破冰 + 热乎乎
- 主目标：评论率 ≥8%、关注 ≥5%、灯牌 ≥3%
- 话术：开场拉新 / 关注理由 / 灯牌理由 / 看小黄车
- 动作顺序：评论 → 关注 → 灯牌 → 看小黄车

## 第 2 轮：价值塑造 + 项目化内容输出
- 主目标：评论 10%、CTR 升
- 话术：价值塑造 / 真实场景 PBL / 互动引导

## 第 3 轮：五分钟成交 — 福利 · 紧迫 · 保障 · 倒计时
- CTR ≥15%、下单率 ≥12%
- 话术：福利锚点 / 紧迫 / 保障 / 五分钟成交

## 第 4 轮：痛点刺激 + 案例见证
- 评论率冲 10%、停留 ≥1.5 分钟
- 话术：痛点拆解 / 案例输出 / 算时间账

## 第 5 轮：未来格局 + 价值锚点
- 点赞 / 评论到阈值即加推 3–5 个名额
- 话术：趋势与能力 / 编程思维四能力

## 第 6 轮：终极冲刺 — 清库存 + 终极倒计时
- 60 秒倒计时 + 未下单预告
- 话术：清库存加码 / 终极保障 / 60 倒计时
