# North Star · 长期目标锚点

> **AI 必读** — 这是库主「我要去哪」的官方版本。每次会话必读，让 agent 拿到一致的长期坐标。
> 如果变化，更新这份文件 + [[../10_Profile/我要去哪]]，保持两份同步。

## 一句话使命

让**四个徒弟**和我自己，借助 AI 时代，在**教育 + 自媒体**两条赛道建立可持续的事业。

## 当前阶段（2026）

**职业身份**：乐启享机构成员 / 愈见森林个人 IP

**两条赛道**：
1. **教育**：教学产品化（7 天训练营可规模化复制）
2. **自媒体**：抖音个人 IP（目标 10000 粉）

**当前能力**（详见 [[../10_Profile/能力地图]]）：
- 全栈开发（Web + 桌面 + 移动）
- AI 编程（Codex / Claude Code / Cursor / Trae）
- 教学 / 直播 / 自媒体
- 知识管理（这套 Obsidian 系统就是证明）

## 这一年（2026 年）要拿到的三个结果

### 1. 教学产品化（Q3 重点）
- 把「7 天 Vibe Coding 营」做成可复制的标准化产品
- 有定价、有 SOP、有学员成功案例
- 至少跑 2 期，每期至少 10 人完课
- **度量**：完课率 ≥ 80%，学员 NPS ≥ 7

### 2. 抖音 10000 粉（持续）
- 当前 ~150 粉
- 持续输出 AI 编程 + 教育方法论 + 真实工作过程
- 直播常态化（每周至少 1 次）
- **度量**：月底粉丝数 / 完播率 / 互动率

### 3. 知识库系统化（这条会话做的事）
- Obsidian vault 达到「专业级 AI 记忆库」水平
- 四个徒弟也能基于这套方法搭自己的
- 内容沉淀可被 AI 检索、可被徒弟复用
- **度量**：所有内容可被 1 次 grep 找到；agent 启动后不需要重新解释身份

## 不做的（明确边界）

- ❌ 不做外包项目（不接单，不浪费时间）
- ❌ 不做不赚钱的直播 / 课程
- ❌ 不为了流量做没营养的内容
- ❌ 不学的技术：纯算法岗、底层嵌入式、企业级后台（与目标无关）

## 决策原则（库主用来做选择的）

1. **时间放大**：这件事能不能让我将来做更少的事？
2. **可复用**：做一次能用很多次吗？
3. **杠杆**：能让徒弟、学员、粉丝一起受益吗？
4. **能量**：做了之后我会更有劲还是更累？

四个都「是」就做。三个「是」谨慎做。两个以下不做。
