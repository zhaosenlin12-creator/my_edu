# 知识库快速使用指南

> 这是一份“打开就能用”的速查。完整说明在 [使用说明](C:\my_know\00_Home\使用说明.md)。

## 1. 打开 Obsidian

Obsidian 不是普通编辑器，它把文件夹当成“数据库”，每个 Markdown 是数据库里的一行。

```powershell
Start-Process "C:\kaifa_boot\Obsidian\Obsidian.exe" -ArgumentList "C:\my_know"
```

如果打开后看到的是“选择 Vault”，点 `打开另一个库` → 选择 `C:\my_know`。

## 2. 你能看到哪些目录

打开后左侧文件树就是知识库的目录。

- `00_Home`：本周焦点、模板和总索引
- `10_Profile`：我是谁、我在哪、我要去哪、能力地图
- `20_Projects`：34 张项目卡 + index
- `30_Teaching`：5 张教学卡 + 学员镜像 + 新生成的课程计划
- `40_Content`：抖音、直播卡 + 草稿
- `50_AI`：9 张 AI / 开发工具卡 + 一个完整 Skill
- `60_Assets`：CSV 索引、仓库总账、直播汇总
- `70_Sources`：VibeHub 484 个中英页面 + CSV 索引
- `80_Canvas`：能力地图画布
- `90_Archive`：归档
- `90_Scripts`：5 个执行脚本

## 3. 5 个执行脚本（直接调用）

```powershell
# 抖音选题草稿
python C:\my_know\90_Scripts\douyin_topic_picker.py

# 直播复盘：填一次数据，自动写卡 + 追加 CSV
python C:\my_know\90_Scripts\live_recap.py --date 2026-07-28 --title "今晚的直播主题" --peaks 100 --new-followers 12 --conversions 2 --qa "作业点评" --failure "" --improvement "开场再快 1 分钟"

# 课程计划：填名字、年级、节数直接生成
python C:\my_know\90_Scripts\course_planner.py --name "Vibe Coding 入门" --grade "四年级" --lessons 6 --goals "理解 prompt" "跑通一个网页" --deliverables "可发布网页"

# 知识卡索引：扫整个 Vault 出 CSV，给 Excel 用
python C:\my_know\90_Scripts\build_knowledge_index.py

# 代码审查：在指定仓库的暂存 diff 上扫密钥 / 风险路径
python C:\my_know\90_Scripts\code_review.py --repo C:\kaifa\game-google
```

## 4. 6 个工作流模板

都在 `C:\my_know\00_Home\_templates\`：

- `weekly_review.md` — 每周复盘（数据对比 + 下周 3 件事）
- `douyin_topic.md` — 抖音选题卡（钩子 + 行动指令 + 发布后跟踪）
- `live_script.md` — 直播话术模板（6 轮节奏 + 风险兜底）
- `project_brief.md` — 项目启动卡（验收标准 + 时间盒 + 风险）
- `code_review.md` — 代码审查清单（自检 + AI 协审 + 教学项目额外项）
- `course_plan.md` — 课程计划模板（结构 + 课节表 + 评价）

## 5. 与 Codex 的搭配

- Codex 不直接“代替”你写代码 / 写直播稿。
- Codex 做：读仓库、整理笔记、生成候选草稿、执行自动化。
- 你做：选目标、审 diff、读最终稿。
- 终态产物：项目卡、课程计划、抖音草稿、直播复盘。
