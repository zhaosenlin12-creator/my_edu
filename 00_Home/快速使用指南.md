# 快速使用指南

> 5 分钟上手。读完这一页你就能自己新增卡片、定位档案、用 Obsidian 检索。

## 1. 打开 vault
- Obsidian 桌面：`C:\kaifa_boot\Obsidian\Obsidian.exe` 用 `-ArgumentList 'C:\my_know'` 直接打开
- GitHub 远程：`https://github.com/zhaosenlin12-creator/my_edu.git`
- 本地根：`C:\my_know`（HEAD `37c22be`）

## 2. 走一遍哲学三问
- [[10_Profile/我是谁]] · 我在做什么、有什么证据

## 3. 找东西的 4 条入口
1. **MOC 入口**：`[[00_Home/MOCs/projects]]` / `[[00_Home/MOCs/teaching]]` / `[[00_Home/MOCs/content]]` / `[[00_Home/MOCs/ai_tools]]`
2. **dossier 入口**：`[[60_Assets/dossiers/]]`（真实证据层，7 个核心档案）
3. **数据入口**：`[[60_Assets/codex-session-digest.json]]` / `[[60_Assets/GitHub仓库总账]]` / `[[60_Assets/_inventory]]`
4. **检索**：Obsidian 全局搜索框 + 命令面板 `Ctrl+P`

## 4. 新增一条怎么写
走“先 dossier → 再卡片 → 再更新能力地图”的顺序：

```
Step 1: 60_Assets/dossiers/<name>.md
  - 必填 frontmatter: type: dossier / status / domain / audience / repo / local_path / related / updated_at / tags
  - 正文：一句话 / 仓库本地 / 技术栈（实测自 package.json）/ 关键证据（行号 + 文件）/ 已知痛点 / 我学到的能力 / 下一步
Step 2: 20_Projects/<name>.md 或 30_Teaching/<name>.md 或 40_Content/<name>.md
  - 必填 frontmatter: type / status / domain / audience / repo / url / dossier: "[[60_Assets/dossiers/<name>]]"
  - 正文：必须能跳回 dossier
Step 3: 更新 10_Profile/能力地图 的角色叠加或当前能稳定交付
```

## 5. 卡片 frontmatter 字段约定
- `type` ∈ profile / project / teaching / content / dossier / ai / inventory / how-to / readme / template
- `status` ∈ active / archived / draft
- `domain` 自由词，可多个
- `audience` 自由词，可多个（self / student / teacher / parent / apprentice）
- `repo` GitHub 仓库 URL 或本地路径
- `url` 公开部署地址
- `dossier` 反向链回 [[60_Assets/dossiers/]]，保证证据闭环
- `summary` 一句话总结
- `next_action` 下一步要做什么
- `updated_at` 必须是 YYYY-MM-DD

## 6. 提交与同步
```bash
# 编辑完一张卡就提交
cd C:\my_know
git -c core.autocrlf=false add -A
git diff --cached --check
git -c core.autocrlf=false commit -m "dossier: <一句话>"
git push origin main
```
