# 知识库使用说明

## 每天开始工作
1. 打开 [[10_Profile/我在哪]]，确认当前主线。
2. 打开 [[00_Home/本周最重要的事]]，只选一个最重要动作。
3. 开发任务先搜 [[20_Projects/index]]，再打开对应项目卡。
4. 不知道术语时，搜索 `70_Sources/vibe-hub/index.csv` 或 VibeHub 本地页面。

## 开发时怎么配合
- 把仓库路径、目标、约束和验收标准交给 Codex。
- 让 Codex 先读项目，再修改代码。
- 用 IntelliJ IDEA 打开工程，确认依赖、编译、运行、测试和调试。
- 完成后把真实结果写回项目卡的“状态”和“下一步”。

## 新增一张知识卡
1. 从 `00_Home/_templates` 复制正确模板。
2. 填写 `type`、`status`、`domain`、`summary` 和 `next_action`。
3. 写清来源、已验证事实和未确认判断。
4. 至少关联一张项目、课程、内容或工具卡。

## 直播和教学复盘
- 直播数据写入 [[40_Content/curerforest-channel]] 或对应内容卡。
- 课程改进写入 [[30_Teaching/index]] 或具体课程卡。
- 课堂中出现的技术错误，沉淀到项目卡或 AI 工具卡。

## 每周日复盘
- 哪个目标完成了？
- 哪个动作浪费了时间？
- 哪个结论已经被真实项目验证？
- 下周只保留三件最重要的事。
