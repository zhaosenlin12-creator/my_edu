# AI 编程学习路线

> 每一阶段都遵循：理解术语 → 准确表达 → 项目实作 → 讲给别人 → 留下证据。

## 第 1 阶段：能和 AI 说清楚（第 1-2 周）
学习：`ai-basics`、`system-prompt`、`context-window`、`structured-output`、`ai-hallucination`。

验收：
- 能写清目标、输入、输出、约束和验收标准
- 能指出 AI 回答中的事实、推断和待验证项
- 完成一个结构化输出的小任务

## 第 2 阶段：能完成一个网页（第 3-4 周）
学习：`html`、`component`、`state`、`responsive-design`、`deployment`、`env-var`。

验收：
- 独立做出一个响应式页面
- 能说明组件、状态和数据从哪里来
- 发布到 Cloudflare Pages 或 Vercel

## 第 3 阶段：能安全迭代（第 5-6 周）
学习：`git`、`branch`、`commit`、`diff`、`pull-request`、`rollback`、`worktree`。

验收：
- 每人一个 GitHub 仓库
- 使用分支完成一次功能并合并
- 能通过 diff 审查 AI 改了什么
- 能回滚一次错误提交

## 第 4 阶段：能做 AI 功能（第 7-9 周）
学习：`api`、`json`、`tool-calling`、`conversation-history`、`token-cost`、`rate-limit`。

验收：
- 接入一个模型 API 或现成 AI 服务
- 密钥不进入 Git
- 有超时、失败提示和输出校验
- 记录一次成本与风险复盘

## 第 5 阶段：能带人交付（第 10-12 周）
学习：`prd`、`mvp`、`user-flow`、`acceptance-criteria`、`test-case`、`e2e-test`。

验收：
- 把一个想法写成一页 PRD
- 拆成不超过两周的 MVP
- 为关键流程写验收标准
- 向团队演示并完成复盘

## 四位徒弟共同节奏
- 周一：选 5 个术语，结合当前项目提问
- 周三：完成一个可运行实作
- 周五：互相讲解并做 Git diff 审查
- 周日：把方法、错误和证据写回各自知识库
