1. 07:30-08:10 热点扫描（抖音 + GitHub 7 天 + 官方产品页 + 对标账号 3 个角度）

## 选题打分维度（5 项 × 5 分）
- 最近 7 天内够不够新
- 8 秒内能不能看懂结果
- 普通人能不能马上理解价值
- 有没有官方站和 GitHub 仓库可挂
- 能不能延展成至少 3 条系列

## 监测指标（每天必看）
| 指标 | 用途 |
|---|---|
| 播放量 | 推荐链路有没有打开 |
| 收藏率 | “留着以后用”的价值 |
| 新粉数 | 是否在替账号增长 |
| 新粉率 | 新粉数 / 播放量（目标 0.2% → 0.8%） |
| 主页访问率 | 是否把人带回主页 |
| 完播率 | 开头和节奏有没有留住人 |

## 当前关键诊断（2026-07-13-account-audit.md）

- 数字目标：1000-3000 粉基准 / 5000 粉冲刺 / 至少 3 条 1 万+ 播放
