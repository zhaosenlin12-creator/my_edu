# Dossier · 乐其翔展览系统（leqixiang-display-system）

> 这是我从 package.json / 源码 / dist 数据三处读到的事实，不是项目名猜测。

## 一句话
一个用 Vite + React 19 + TypeScript 5.9 写的**少儿科创机构展览大屏站**，把学生作品 / 课程 / 价格 / 教师能力全部铺在墙上，给家长、学生和来访者一个可点可看的“学校门面”。强项是**资源预热 + web-vitals 自监控 + 离线 kiosk 部署**。

## 仓库与本地
- 本地仓：C:\kaifa\open_leqixiang
- 远程仓库：暂未推 GitHub（GitHub 总账里没有对应项）

## 数据模型（来自 src/types/content.ts）
ContentBundle 由十块 JSON 拼出，挂载路径 `/content/*.json`：
- site：name / tagline / contact.phone / contact.address / settings.idleSeconds / settings.defaultSlideSeconds
- modules：id / title / enabled / order / summary / coverAssetId
- courses：stages (CourseStage) + routes (CourseRoute)；stage 含 ageRange / tagline / highlights
- tours：Tour → TourNode[]；node.type = scene / asset / module
- playlists：type ∈ image / video / announcement / course / tour / pricing / module
- pricing：public.range / public.highlights + advisor.assets
- achievements：competitions[] + showcases[]
- students：**policy: 'manual-review'**；showcases[] 含 assetId + summary
- staff：**mode: 'capability-template' | 'real-profiles'**；capabilities[]
- assets：source ∈ website / pdf / student-archive / generated / manual

## 关键证据
- 学生档案有人工审核门槛：`StudentsConfig.policy = 'manual-review'`（src/types/content.ts:75）
- 教师信息默认走能力模板：`StaffConfig.mode = 'capability-template'`（src/types/content.ts:84）
- 数据自动生成：src/data/exhibition.ts 顶部注释 `// AUTO-GENERATED by scripts/rewrite-exhibition.mjs`，**不要手改**
- 性能监控内置：src/lib/perf.ts 监听 LCP / CLS / INP + longtask，写入 50 条 ring buffer 到 `window.__leqxPerf`，**不上报网络**（kiosk 离线）
- 启动时预热学生档案：src/main.tsx 调用 `warmStudentGallery(2000, 12)`（空闲 2 秒后预热前 12 张缩略图，防白屏 8x 闪烁）
- 大组件懒加载：src/App.tsx 用 React.lazy 加载 HeroCarousel / CategoryStage / LayeredDrawer
- 自检脚本：scripts/smoke-browser.mjs（17KB），失败常因 `/assets/brand/logo.png` 缺失
- CSS 延迟加载：构建链 `node scripts/postbuild-css-defer.mjs` + `node scripts/emit-cache-headers.mjs`
