# 级联选择器Cascader

你可能会说

选地址那种，先选省、再选市、再选区，一层层点下去。

**点开一个选项后继续选择下一级，常见于省、市、区选择**·例如填写收货地址时，先选“广东省”，再选“深圳市”，最后选“南山区”，完成后要显示整条路径。若用户需要同时选择多个地区，用 [树选择 **TreeSelect**](/tree-select) 更合适。

### 什么时候用

- **省市区地址**：常见的级联选择场景

  省 / 市 / 区广东省深圳市南山区
- **组织架构**：公司 → 部门 → 小组

  技术中心 / 前端组技术中心 ▸平台研发 ▸前端组
- **商品 / 内容类目**：大类 → 小类 → 具体分类

  数码电器 ▸手机通讯 ▸智能手机
- **选中后回显完整路径**：让用户确认自己选了哪

  地址广东省 / 深圳市 / 南山区

### 什么时候不用

- **数据只有一层**：使用 [选择器 **Select**](/select)，无需级联

  进行中 ▸进行中数据只有一层，不需要增加二级菜单
- 需要**勾选多个分支**：按选择规则评估 [树选择 **TreeSelect**](/tree-select)

  研发部 ×2

  ☑ 研发部☑ 前端组☐ 后端组☐ 设计部
- 每层只有少量选项时，直接平铺会更快

  公开仅成员私密
- **选项较多且用户需要搜索**：使用可搜索级联
