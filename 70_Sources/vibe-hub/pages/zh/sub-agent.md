# Sub-agent

你可能会说

大任务能不能拆给几个帮手同时干，最后汇总给我？

**Sub-agent 是主 Agent 临时请来专门处理一部分工作的另一个 Agent，常见于并行研究、测试和审查。**·例如上线前，主 Agent 可以让一个 Sub-agent 检查页面文字，另一个检查手机布局，再汇总两边结果。它不会自动知道全部背景，任务范围、可用权限和返回内容要由主 Agent 说明。
