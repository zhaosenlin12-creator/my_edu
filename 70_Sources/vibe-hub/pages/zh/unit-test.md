# 单元测试Unit Test

你可能会说

先单独测一下总价计算函数，优惠券、运费和边界值都别连真实支付。

**单元测试是针对一个可独立验证的函数、模块或组件进行的测试。**·例如给总价函数输入商品、优惠券和运费，再检查输出是否正确；按钮组件也可单独验证禁用时不会触发操作。它强调小范围和快速定位，不负责证明前端、接口与数据库已经能一起工作。
