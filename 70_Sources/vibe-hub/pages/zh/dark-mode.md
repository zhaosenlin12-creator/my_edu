# 深色模式Dark Mode

你可能会说

给产品加真正的深色模式，文字、边框、图表和代码块都要跟着切换。

**深色模式是一套可切换的深色界面主题状态，而不只是把页面背景涂黑。**·例如用户选择深色模式或系统偏好深色时，页面的背景、文字、边框、按钮、图表和聚焦状态都换成协调且足够对比的值。它服务于不同环境和偏好；一张黑色海报或深色视觉风格并不自动构成可切换主题。
