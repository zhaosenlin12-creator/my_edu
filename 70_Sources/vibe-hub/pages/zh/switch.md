# 开关Switch

你可能会说

像手机设置里那样，这个功能一拨就开、再拨就关。

**开关是表示并立即切换一项功能开启或关闭状态的表单控件**·深色模式或自动保存适合用开关，并应在切换后反馈成功或失败。若多个设置需要统一保存，应改用 [复选框 **Checkbox**](/checkbox) 配合按钮。

消息通知
深色模式

### 什么时候用

- **设置页**里的开 / 关项

  消息通知

  深色模式
- 拨完**立即生效**，最好给个反馈

  自动保存已开启自动保存
- **功能列表**逐个启用、停用

  API 访问

  Webhook
- **实验功能**的灰度入口

  实验新版编辑器

### 什么时候不用

- **提交后才生效**的偏好：使用 [复选框 **Checkbox**](/checkbox) 配合 [按钮 **Button**](/button)

  接收营销邮件

  提交
- **危险操作**（如删除全部数据）：需要确认，不宜使用开关

  删除全部数据

  一个开关就删掉所有数据？
- **三个以上互斥状态**：使用 [单选框 **Radio**](/radio)

  公开仅成员私密
- **同意协议**等确认：使用 [复选框 **Checkbox**](/checkbox)
