# 盒模型Box Model

你可能会说

这个卡片明明设为 320px，为什么加了内边距后反而挤出容器？

**盒模型是浏览器计算元素内容、内边距、边框和外边距所占空间的规则。**·例如卡片内容宽 320px，再加左右内边距和边框，实际占用宽度可能更大，导致两列排不下；按钮的可点击区域也受这些层次影响。它解释尺寸怎样算，不负责内容超出后该显示、裁切还是滚动。
