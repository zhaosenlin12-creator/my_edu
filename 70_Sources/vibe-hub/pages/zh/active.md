# 按下Active

你可能会说

点下去那一瞬间，按钮要有个被按瘪的感觉。

**按下是控件从指针按下到松开期间呈现的短暂交互状态**·active 通常出现在指针按下到松开之间，键盘激活也应有对应反馈。可以轻微下沉或改变颜色，但幅度要结合组件、品牌和可读性决定，没有固定缩放值；它不是hover、持续选中或禁用状态。

按住我
只有 hover
列表项也能按
按住左侧按钮可看到缩放变化；右侧按钮没有单独的按下状态

### 什么时候用

- 让按钮轻微下沉或加深颜色，反馈已经按下

  按钮→按钮
- **改变颜色**：不适合缩放的小图标或文字按钮也能表达按下状态

  提交提交
- **反馈及时出现**：按下时应可感知，具体时长随输入方式和动效系统调整

  按下即反馈
- **列表项、[卡片 **Card**](/card) 点按**：需要表达可点击时可补按下反馈；不要让纯展示内容伪装成可操作

  列表项一列表项二（按下中）列表项三

### 什么时候不用

- **与 hover 使用完全相同的样式**：用户难以确认是否已经按下

  悬停按下
- **缺少按下反馈**：用户可能重复触发操作

  确定
- **形变幅度过大**：会干扰按下状态的识别

  按钮
- 把按下样式**当作已选中状态**：active 是短暂状态，选中状态需要持续显示

  按下状态
