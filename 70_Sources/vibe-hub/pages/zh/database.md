# 数据库Database

你可能会说

用户发的内容刷新就没了，得找个地方真正存下来。

**保存并查找用户、文章、订单等应用数据的地方**·比如用户发布文章后，后端把标题和正文写入数据库；刷新页面或重新登录时，文章仍能被读取。CRUD 是创建、读取、更新和删除这四类常见数据操作。只保存在当前浏览器的内容不会自动出现在另一台设备上。
