# 图标Icon

你可能会说

按钮上加个小图形，让人不看字也知道是干嘛的。

**图标是用统一的小型视觉符号表示功能、对象或状态的界面元素**·搜索、下载和关闭可用熟悉图标帮助扫读。陌生或高风险操作不能只放图标，应补上文字或[文字提示 **Tooltip**](/tooltip)。

也常被叫作*界面图标**功能图标*

*⌕*搜索*↓*下载*⚙*设置

容易混淆？这样区分

图标Icon**≠**[图片 **Image**](/image)

icon 是小而可复用的功能或概念符号；[图片 **Image**](/image) 用来展示照片、插画或内容本身。

图标Icon**≠**[按钮 **Button**](/button)

icon 只负责表达含义；把图标放进 [按钮 **Button**](/button) 并让它执行动作，才组成图标按钮。

### 什么时候用

- **常见工具操作**：搜索、关闭、下载

  ⌕↓×搜索 · 下载 · 关闭
- **紧凑工具栏**：在有限空间组织一组操作

  ↶↷⌗⋯
- **状态提示**：配合文字帮助浏览

  ✓文件已经同步

### 什么时候不用

- 陌生操作只放图标：补充文字或 [文字提示 **Tooltip**](/tooltip)

  ◈图标含义不清楚
- 将不相关的危险操作混入同一个“更多”菜单

  ⋯删除项目藏在“更多”里
- 用 Emoji 替代需要统一线条和语义的系统图标

  ⬇📥⇩三个下载图标，风格各不相同
