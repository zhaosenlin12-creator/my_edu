# ReAct

你可能会说

AI 做事能不能别一口气闷头干，做一步、看一步？

**让 Agent 反复执行“判断下一步—调用工具—读取结果”的任务模式。**·例如整理竞品资料时，Agent 先判断还缺什么，调用搜索工具，读取结果，再决定继续查证还是开始汇总。ReAct 描述这组任务动作，不负责工具权限和最多能尝试多少次。
