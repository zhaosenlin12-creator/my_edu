# MCPModel Context Protocol

你可能会说

AI 想读我的日历和文件，总得有个统一的接法吧？

**MCP 是让 AI 应用连接日历、文件、数据库等外部工具和资料的一套通用协议。**·例如接入日历 MCP 服务器后，Agent 可以发现“查询日程”工具并提出查询请求；服务器返回真实日程，应用再显示结果。MCP 只规定连接和通信方式，不会自动授予日历权限。
