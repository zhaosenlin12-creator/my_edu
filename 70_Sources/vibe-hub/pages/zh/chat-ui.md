# 聊天界面Chat UI

你可能会说

把这个聊天窗口补全消息列表、输入区、发送中和失败重试，别把错误藏起来。

**聊天界面是组织消息列表、输入区和对话反馈状态的交互界面。**·例如用户发送一条问题后，界面应把自己的消息放入列表，显示等待或流式输出，并在失败时保留可理解的错误和重试入口；客服聊天和 AI 对话都需要这些界面能力。它是用户看见和操作的壳，不等于里面连接的模型或客服系统。
