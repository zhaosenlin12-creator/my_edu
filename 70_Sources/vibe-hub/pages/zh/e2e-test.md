# 端到端测试End-to-End Test

你可能会说

像游客本人一样，从选择日期、预订行程一直点到确认页，把整条流程跑一遍。

**端到端测试是从用户入口驱动完整系统流程并检查最终可见结果的测试。**·例如在浏览器里选择旅行日期、填写乘客、完成沙盒支付，再确认订单页出现正确行程。它会跨过页面、接口和数据存储，但不等于每个内部分支都已覆盖。
