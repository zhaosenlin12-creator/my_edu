你可能会说

这个月 API 账单炸了，钱到底花在哪了？

**Token 用量会逐轮累加，实际成本还要按所用模型的价格表计算**·系统规则、聊天记录、文件、工具结果和模型回答都会产生 Token，多轮任务需加总每轮输入与输出。用量是 Token 数量；成本还取决于模型及输入、输出、缓存的不同价格，外部工具也可能单独收费。
