# 数字输入框InputNumber

你可能会说

数量那里只能填数字，最好能直接按加减。

**数字输入框是用于填写数值并按设定步长增减的表单控件**·购买数量、库存和价格可在这里直接输入或点加减号调整。它只能限制格式和范围，库存是否足够等业务规则仍要在提交时校验。

先知道

[输入框 **Input**](/input)

也常被叫作*Number Input**数字步进器**Numeric Stepper*

容易混淆？这样区分

数字输入框InputNumber**≠**[步骤条 **Steps**](/steps)

有些设计系统也把加减数字的控件叫 Stepper，因此单独说 Stepper 容易产生歧义。[数字输入框 **InputNumber**](/input-number) 用来增减一个数值；[步骤条 **Steps**](/steps) 用来展示流程包含几个阶段。

### 什么时候用

- **购物车改数量**：点加减比敲键盘快

  机械键盘−2＋
- **设置库存、限购**：整数且有业务含义

  库存−50＋
- **有明确上下限**：超出范围自动拦下

  −1＋

  最小 1、最大 99，超出会被拦下
- **价格、金额**：需要固定小数位

  价格19.90元

  自动保留两位小数

### 什么时候不用

- **手机号、身份证号**属于数字字符串：使用 [输入框 **Input**](/input)

  手机−138\*\*\*\*6688＋

  手机号又不能加减
- 只需**近似选择数值**：使用 [滑块 **Slider**](/slider)

  预算≈ 450
- 需要选择**日期或年份**：使用 [日期选择器 **DatePicker**](/date-picker)

  2026-07-21 📅

  日期有专门的选择器
- **数值范围很大**：支持直接键盘输入，不只依赖加减按钮

  −12,800＋
