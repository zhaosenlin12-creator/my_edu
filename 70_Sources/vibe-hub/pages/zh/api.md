# API

你可能会说

我的网页想从后台拿数据，听说要有个什么“接口”，到底是啥？

**两个软件互相请求数据或功能时共同遵守的约定**·比如天气 App 请求“深圳今天多少度”，天气服务会返回温度和天气状态。API 会说明请求需要带什么、结果长什么样；其中某一个具体请求地址才是端点。API 不是页面、后端代码或数据库。
