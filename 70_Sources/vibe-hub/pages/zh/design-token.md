# 设计令牌Design Token

你可能会说

把主色、间距和圆角整理成设计令牌，别在每个组件里重复写一组数值。

**设计令牌是集中命名和复用颜色、间距、字体等设计值的变量。**·例如把主按钮颜色命名为 `color.brand.primary`、常用间距命名为 `space.16`，组件引用名称而不是各自硬写色值和像素。改主题或统一调整时，令牌能让同一规则在网页、组件库或其他界面保持一致；它不是任意 CSS 变量的别名，也不替代设计决定本身。
