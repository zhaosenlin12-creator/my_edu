# 端口Port

你可能会说

本地项目跑在 3000 端口，接口服务在 4000；帮我确认浏览器连的是哪一个。

**端口是同一台主机上区分不同网络服务的编号入口。**·例如运行 `npm run dev` 后常可在 `http://localhost:3000` 打开网页，同时本机的接口可能监听 4000 端口。localhost 只指当前这台设备；端口让同一台电脑上的多个服务不会混在一起。
