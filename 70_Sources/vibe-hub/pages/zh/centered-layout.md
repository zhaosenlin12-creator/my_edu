# 居中窄栏布局Centered Column

你可能会说

内容别铺满全屏，中间窄窄一条、两边留白，像博客那样。

**居中窄栏布局是一种限制内容栏宽度并将其置于页面中央的页面结构**·文章阅读、登录和设置页面可用居中栏减少视线横向移动，让主任务更集中。具体宽度要根据中文或英文、字号和设备测试；需要品牌说明、帮助入口或多步流程时，可以保留这些必要上下文，不能把所有页面机械压成窄栏。

内容栏*居中限宽 600~720px*

### 什么时候用

- **行宽 60~75 字符**：眼球不用长途移动，见 [排版 **Typography**](/typography)

  ↔ 一行 60~75 字符
- **大留白聚焦**：两侧的空白是设计的一部分

  内容栏
- **登录、注册**：一张窄卡片放页面正中

  oil-oil••••••••

  登录
- **长文阅读**：正文限宽，配好字号行高

  正文的字号与行高要清楚易读，长文才容易持续阅读。

### 什么时候不用

- 宽屏正文**未限宽**：单行字符过多会影响阅读
- 窄栏放入仪表盘：**网格空间不足**，数据界面可使用 sidebar-layout
- 登录卡片**未居中**：会造成两侧留白失衡

  登录卡片
- 长正文使用**居中对齐**：每行起点不一致，阅读效率降低

  这是一段居中对齐的长正文，每行的起点都不一样，读两行就开始费劲。
