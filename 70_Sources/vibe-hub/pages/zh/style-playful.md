# 趣味插画Playful Illustration

你可能会说

活泼一点，配上有趣的插画和角色，别太严肃。

**趣味插画是一种用角色、场景和夸张图形建立品牌个性的视觉方向**·它常与鲜明配色、圆润形状和轻量动效搭配，适合教育、创作和年轻消费产品。插画负责表达语气，不能遮挡正文、表单和主要操作。

设计原则 · Principles

- **先设计一个可识别的角色语气**：颜色、字体、插画和文案表达同一种性格
- **把夸张留给重点**：大标题、成功反馈或关键插画可以跳出来，其余区域安静配合
- **圆润不等于含糊**：按钮、输入和状态仍要有清楚边界与文字
- **动效表达因果**：完成、拖动和升级可以有弹性，但不能拖慢任务

### 什么时候用

- **教育、创作者和轻量效率产品**：需要降低第一次使用的心理门槛

  ◡

  TODAY**Three tiny wins!**

  *+3*
- **年轻消费和社区品牌**：个性与亲近感是重要差异

  ✦**Friendly, not childish**Clear action first
- **产品拥有吉祥物或插画体系**：角色可以贯穿空状态、反馈和引导
- **任务容易让人焦虑**：温和语言和积极反馈能减轻压力

### 什么时候不用

- **过多元素同时跳动、旋转或变色**：会持续打断注意力，弱化重要内容

  **BOUNCE! POP! WOW!**Every element shouts at the same volume
- **将儿童化等同于友好**：面向成年人的产品也应保持内容与语气的尊重
- **亮色文字缺少对比**：鲜艳背景上仍需要稳定可读的文字层
- **严肃结果只用表情回应**：支付、权限和错误仍要准确说明
