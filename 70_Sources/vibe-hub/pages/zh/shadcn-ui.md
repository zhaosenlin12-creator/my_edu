# shadcn/ui

你可能会说

有没有一套好看的现成组件，代码直接复制进项目就能改？

**shadcn/ui 是一套可复制进 React 项目并直接修改的界面组件代码，常见于按钮、表单和弹窗。**·例如添加 Button 后，项目里会多出一个按钮组件文件；你改这份文件，网站里的按钮也会跟着变。它不是在线组件服务，后续维护要由项目自己负责。
