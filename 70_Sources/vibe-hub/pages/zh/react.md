# React

你可能会说

老听人说做网页要用 React，它到底比直接写页面强在哪？

**React 是用组件和状态制作交互网页界面的 JavaScript 库。**·例如把商品加入购物车后，右上角数量从 2 变成 3；React 根据新的购物车数据更新这处数字。商品是否真的加入、刷新后还在不在，仍取决于后端和数据保存。
