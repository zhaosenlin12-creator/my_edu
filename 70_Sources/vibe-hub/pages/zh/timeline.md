# 时间轴Timeline

你可能会说

物流到哪一步了，按时间排出来，让用户看得明白。

**时间轴是按时间顺序展示一组事件、状态或记录的数据组件**·物流记录可依次显示“已下单、已发货、运输中”。需统一最新事件放在上方或下方，并用文字说明状态，不能只靠颜色和圆点。

**运输中**07-19 09:15

### 什么时候用

- **物流 / 订单进度**：已下单 → 已发货 → 已签收

  已签收 · 今天 14:32

  运输中 · 昨天 09:15

  已下单 · 前天 20:02
- **审批 / 操作记录**：谁在什么时候做了什么

  oil-oil 通过了审批

  林小hu 提交了审批

  创建了审批单
- **更新日志**：版本记录按时间排开

  v2.4 新增暗色模式

  v2.3 修复 12 个问题

  v2.2 上线协作功能
- 节点有**成败状态**时，用文字或图标说明结果，颜色只作辅助

  部署成功

  构建中…

  测试失败

### 什么时候不用

- 需要用户依次完成的任务应使用 [步骤条 **Steps**](/steps)，而不是时间轴

  *1*填写信息*2*确认订单*3*完成支付
- 时间顺序不重要的普通消息应使用 [列表 **List**](/list)

  今天开周会

  中午一起吃饭

  和时间先后无关，普通列表就行
- 内容**没有时间先后**，不适合使用时间轴

  功能 A

  功能 B

  功能 C
- 节点包含大段图文时，平铺为 [卡片 **Card**](/card) 通常更易阅读

  版本发布公告

  节点内容太重，用卡片平铺
