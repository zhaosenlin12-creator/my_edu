# Token

都说按 token 收费，token 到底是个啥？跟我打几个字什么关系？

**Token 是语言模型读取和生成文本时使用的文字、标点或代码片段单位**·同一句话在不同模型中可被切成不同数量的 Token。例如，输入和输出的片段数会影响可放内容、等待时间和用量；一个汉字不保证正好是一个 Token。
