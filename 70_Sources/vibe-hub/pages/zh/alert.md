# 警告提示Alert

你可能会说

页面上方要一直挂着一条黄色提示，告诉用户账号快到期了。

**警告提示是嵌在页面内容中、持续说明状态、风险或异常的提示组件**·账号即将到期可在设置页相关位置显示警告提示。它不阻断当前操作，但重要程度不能只靠颜色，需同时使用标题、图标和文字。

### 什么时候用

- **表单提交失败**：把错误汇总钉在表单上方

  ⚠ 2 处填写有误，请检查后重试*邮箱**密码*
- **系统维护 / 升级公告**：全局生效，人人都得看到

  📢 本周六 02:00-04:00 系统维护，期间暂不可用
- **危险操作区域**：提前说清后果，而不是事后报错

  ⚠ 删除后不可恢复，操作前请确认已备份

  删除项目
- **页面状态提醒**：草稿未发布、体验版、权限受限

  ⓘ 当前是未发布草稿，仅自己可见

### 什么时候不用

- 只是“保存成功”等瞬时反馈：使用 [轻提示 **Toast**](/toast)

  ✓ 保存成功一句话的成功，用不着一直挂着
- 需要用户做出选择：使用 [弹窗 **Modal**](/modal) 或 [气泡确认框 **Popconfirm**](/popconfirm)

  ⚠ 删除需要明确确认

  删除
- 持续提示过多：重要程度与阅读顺序会变得模糊

  ⚠ 密码即将过期⚠ 有 3 条未读公告ⓘ 新功能已上线
- 将营销广告伪装成警告：会削弱用户对提示的信任

  🎉 限时 5 折！马上升级会员
