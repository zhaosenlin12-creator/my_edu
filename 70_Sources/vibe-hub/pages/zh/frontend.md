# 前端Frontend

你可能会说

老听人说前端、后端，这两个到底有什么区别？

**用户在网页、小程序和软件里直接看到、点击和输入的那一层**·例如，在注册页，输入框、提交按钮和“正在提交 / 注册成功 / 出错了”的提示属于前端；账号是否真正创建成功，要由后端处理后返回结果。
