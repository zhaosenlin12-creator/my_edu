# 用户流程User Flow

你可能会说

帮我画一下，用户从进来到完成下单，中间都经过哪几步。

**画出用户从入口到完成目标所经过步骤和分支的路径图**·例如，注册流程可以包含进入注册页、填写资料、验证码成功或失败，以及完成注册。它只保留影响用户前进的关键步骤，不必画出页面里的每一次点击。
