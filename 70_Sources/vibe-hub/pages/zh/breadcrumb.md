# 面包屑Breadcrumb

你可能会说

页面层级太深了，顶上显示一下当前在哪，能点回上一层。

**面包屑是按层级展示当前页面路径、帮助用户返回上级的导航组件**·“首页 / 项目 / 设置”可让用户看懂当前位置并返回项目页。上级通常可点击，当前页只说明位置，不需要链接到自己。

首页/
组件/
面包屑

### 什么时候用

- 站点有**多级层级**，需要标明当前页的位置

  首页/组件/导航/面包屑
- 用户想**快速回到上一级**，点链接直接跳

  组件库/导航/面包屑点「导航」直接回上一层
- 文件目录、商品分类这类**树状结构**

  云盘/设计组/2026 改版/首页.sketch
- 深层页面配合 [导航菜单 **Menu**](/menu)，帮助用户确认当前位置

  工作台/项目/官网改版/任务/详情

### 什么时候不用

- 页面层级很浅：标题通常已足够说明位置

  首页/设置
- 表示**操作步骤**：使用 [步骤条 **Steps**](/steps)

  填写信息/确认订单/完成支付这是步骤，不是路径
- 路径太长**不收缩**，一行放不下全摊开

  首页/产品/企业版/解决方案/零售行业/客户案例/案例详情
- 当前页做成**可点击链接**，无法带来新的导航结果

  首页/面包屑当前页不应链接到自身
