# 回归测试Regression Test

你可能会说

这次只改了优惠券，也要确认原来的支付、退款和订单查询没有被带坏。

**回归测试是确认一次修改没有破坏原本正常功能的测试。**·例如改优惠券规则后，除了验证新规则，还要按风险重跑支付、退款和订单查询的旧用例。只重测刚修复的一个缺陷不能代表完成了所需的回归范围。
