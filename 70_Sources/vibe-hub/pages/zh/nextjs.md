# Next.js

你可能会说

我想用 React 做个完整网站，带路由和 SEO，有没有一站式的框架？

**Next.js 是用 React 制作完整网站的框架，常见于官网、内容站和带登录的 Web 应用。**·例如用户打开 `/products/42` 时，Next.js 根据网址找到商品详情页面，并可先在服务器读取商品数据再显示。它不会自动提供商品数据库或后台权限。
