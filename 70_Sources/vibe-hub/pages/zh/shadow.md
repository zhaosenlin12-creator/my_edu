# 阴影Shadow

你可能会说

给卡片下面加一层淡淡的投影，让它像浮在页面上。

**阴影是通过 box-shadow 在元素周围绘制投影，用来区分界面层级的 CSS 效果**·弹窗、浮动菜单和需要与背景分开的卡片可以用 box-shadow；前两个值控制 x / y 偏移，后面可设置模糊、扩散和颜色。阴影只能辅助表达层级，浅色界面应保持轻微且方向一致；给每张卡片都加重阴影会让页面显得杂乱。

浅中浮起

### 什么时候用

- [卡片 **Card**](/card) **悬停浮起**：浅阴影提示可点

  →
- [弹窗 **Modal**](/modal)、[抽屉 **Drawer**](/drawer) **压在最上层**：阴影更明显
- [选择器 **Select**](/select) 下拉、[文字提示 **Tooltip**](/tooltip) **浮层边缘**：和页面区分开

  全部状态

  全部状态进行中已完成已过期
- **内阴影**做凹陷：输入框、进度槽往里凹

  内阴影可以表现向内凹陷的表面

### 什么时候不用

- 阴影**过深过重**：会让元素层级显得突兀
- **每个元素都加阴影**：会削弱层级区分
- 阴影方向**不一致**：应在全站统一光源方向
- 给**正文文字加投影**会降低字形清晰度，不能替代对比度
