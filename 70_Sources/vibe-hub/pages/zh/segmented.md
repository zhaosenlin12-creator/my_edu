# 分段控件Segmented

你可能会说

就两三个选项并排，点哪个选哪个，像 iPhone 那种切换条。

**把少量选项并排放在一起，点一下就切换当前查看方式**·例如在任务页点击“列表 / 看板 / 日历”，同一批任务会换一种展示方式。它不负责前往另一个页面；选项很多时也不适合全部塞进这里。

先知道

[单选框 **Radio**](/radio)[标签页 **Tabs**](/tabs)

也常被叫作*分段选择器**Segmented Control*

列表看板日历

容易混淆？这样区分

分段控件Segmented**≠**[按钮 **Button**](/button)

[分段控件 **Segmented**](/segmented) 是一组互斥选项，选中一个就会取消另一个；[按钮 **Button**](/button)或按钮组（Button Group）只是执行动作，多个按钮之间不代表互斥选项。

### 什么时候用

- **少量互斥选项**，点选后立即生效：列表 / 看板 / 日历

  列表看板日历
- 只换**展示方式**不换内容：预览 / 源码

  预览源码
- 选项文案**简短明确**：日 / 周 / 月

  日周月

  选项较少，文案简短易扫读
- 工具栏上做**即时筛选**：今天 / 本周 / 本月

  今天本周本月

### 什么时候不用

- 切换整组平级页面内容时，应使用 [标签页 **Tabs**](/tabs)

  概览配置日志
- 选项较多或文案较长时，使用 [选择器 **Select**](/select) 更容易浏览

  全部前端后端设计运营测试选项过多会压缩单项宽度，标签难以快速扫读
- 表单中选择一个值并在提交后生效时，通常使用 [单选框 **Radio**](/radio)

  优先级低中高

  提交

  提交才生效的话，单选框更直白
- 表达功能开关时使用[开关 **Switch**](/switch)；切换视图才使用分段控件

  开关

  只有两个状态，开关更顺手
