# Vibe Coding

你可能会说

我不会写代码，就想用说话的方式让 AI 帮我把东西做出来。

**Vibe Coding 就是用自然语言向 AI 表达需求，让 AI 编写代码，再根据运行结果继续调整。**·例如，你说“做一个待办页面”，AI 会先生成代码；你打开页面，发现按钮太挤或保存报错，再把这些结果告诉它继续修改。它适合快速试想法，但能运行不等于可靠；正式上线前仍要检查代码、测试和权限。
