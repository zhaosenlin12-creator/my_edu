# JavaScript

你可能会说

网页上会动、能交互的那部分，是用什么语言写的？

**JavaScript 是可在浏览器和 Node.js 等运行环境中执行、用于实现交互和程序逻辑的编程语言**·例如，浏览器里的 JavaScript 可在点击“完成”后发送请求，并把待办状态更新到页面；使用 Node.js 的 JavaScript 则运行在服务器。两者是不同的运行环境，密码和可信的权限检查不能只放在浏览器里。
