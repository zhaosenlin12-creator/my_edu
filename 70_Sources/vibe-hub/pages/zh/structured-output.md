# 结构化输出Structured Output

你可能会说

AI 回的一大段话没法直接用，能不能按固定的格式给我？

**结构化输出是要求模型按预先规定的字段和数据类型返回结果的方式**·例如，可把邮件抽取为包含日期、地点和标题的 JSON，供表单或日历读取。格式符合 schema 也不代表数据真实可用，仍要检查日期、金额等业务规则。
