# 上下文窗口Context Window

你可能会说

聊着聊着 AI 把开头说的忘了，是不是它有记性上限？

**上下文窗口是模型在一次请求中能够处理的输入和输出总量上限。**·例如聊了很久后，你再说“按最初要求修改”，最早的要求可能没有被这次请求带入，回答就会跑偏。窗口有大小上限，资料越多也不代表越相关。
