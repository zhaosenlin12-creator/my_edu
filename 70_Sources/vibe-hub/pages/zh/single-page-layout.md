# 单页滚动布局Single Page

你可能会说

所有内容放在一个长页面里，往下滚就能看完。

**单页滚动布局是一种把相关内容按阅读顺序放在同一长页面中的页面结构**·活动页或产品介绍常在一页中依次呈现问题、价值、证据和cta。页面很长时应提供清楚章节、页内跳转和返回路径；内容若分别服务不同任务，就应拆成多个页面，而不是强迫用户一直滚动。

### 什么时候用

- **锚点导航**：钉在页边的分节目录，交给 [锚点 **Anchor**](/anchor)

  产品特性定价客户评价FAQ
- **按信息关系划分章节**：每节承担清楚任务；章节高度由内容决定，不强求正好占满一屏

  核心价值主要优势下一步
- 按照价值、主要优势、证据和行动组织完整阅读顺序

  核心价值→主要优势→可信证据→下一步
- **滚动跟随高亮**：读到哪一节，目录亮到哪

  安装快速上手API常见问题

  滚到「快速上手」，目录自动高亮

### 什么时候不用

- 长页面**缺少锚点和返回顶部**：提供 [回到顶部 **BackTop**](/back-top) 等导航路径
- 同一章节混入多个无关任务，**阅读主线会变得不清楚**；按信息关系拆分或重排

  价值优势证据定价FAQ下一步
- 多模块后台系统通常使用 sidebar-layout，而非单页布局
