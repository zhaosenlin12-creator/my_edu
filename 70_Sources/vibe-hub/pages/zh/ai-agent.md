# AI Agent

你可能会说

我不想一步步指挥，能不能给个目标，让它自己想办法完成？

**AI Agent 是能围绕一个目标自己选择步骤并使用工具的 AI 系统，常见于改代码、整理资料和处理重复工作。**·例如你让它整理会议，它可以读取会议记录、提取决定和待办，再写进文档；每一步会根据实际结果决定下一步。它能使用哪些文件和工具、何时必须确认，仍由产品权限和规则决定。
