# Space

You might say

Everything feels piled together. Adjust the spacing so related things stay close and separate things have room.

**Use empty space to show which things belong together**·Related items should sit close together, while separate groups need more room between them. That empty room is spacing. A product usually defines a small spacing scale so pages follow a visible rhythm instead of using a new value each time.
