# Staging

You might say

Deploy the candidate to staging with production-like configuration and de-identified order data; do not run destructive verification in production.

**Staging is an isolated pre-production environment used to validate a candidate release under production-like conditions.**·A candidate version can run in staging with separate services, test payment, and de-identified orders so the team can check a full deployed flow. Staging is one kind of test environment, not a name for every local, CI-ephemeral, or test URL; its defining role is production-like validation before production.
