# Agent Loop

You might say

The AI stops halfway through. Can it keep working on its own and only ask me when it gets stuck?

**The runtime mechanism that repeatedly calls a model and tools, then decides whether to continue, pause, or stop**·While fixing a page button, a product feeds each read, edit, and check result back to the model and stops after a passing check, a limit, or a request for confirmation. It does not treat “done” in model text as proof.
