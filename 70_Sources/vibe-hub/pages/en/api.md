# API

You might say

My website needs data from the backend. People keep saying I need an API—what is that?

**An agreed way for two pieces of software to request and return information**·For example, a weather app can ask a weather service for today's Shenzhen forecast and receive the temperature and conditions. The API defines where the request goes, what it carries, and what comes back; it is not the page, backend code, or database.
