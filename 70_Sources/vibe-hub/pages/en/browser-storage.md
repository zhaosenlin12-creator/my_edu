# Browser Storage

You might say

Keep this draft after refresh, but do not treat it as a database shared by every user.

**Browser storage is a local web mechanism for keeping data in a person's current browser.**·It can remember dark mode, an unsubmitted form draft, or recently viewed projects so a later page load may restore them. It normally belongs only to that browser and device; clearing data, changing browser, or switching device may remove it.
