# Textarea

You might say

People need to write a longer message here, so one line won't be enough.

**Let the user enter several lines of text**·Comments, descriptions, feedback, and prompts for AI often need a multiline textarea. Give it a useful starting height and, when needed, a character count or resize control. A normal [Input](/en/input) is faster for short, single-line answers.

### When NOT to use it

- Use it for a short value that fits on one line

  title2026 Product Plan v3
- Make a long field so small that writing becomes difficult

  StatusIn progress
- Limit the length without showing the limit

  I want to bold this text and add an image…A plain textarea doesn’t support rich-text editing
- Display read-only content inside an editable-looking box

  A large block of read-only text in a gray field looks like an unfinished form
