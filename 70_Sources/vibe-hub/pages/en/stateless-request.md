# Stateless Request

You might say

Does the AI not actually remember me? Do I have to give it the background again every time?

**A model request that must include the context it needs each time**·If you send only “make the second one shorter” without the earlier titles, the model cannot know what “second” means. A product may save history, but it must choose to send the relevant context again.
