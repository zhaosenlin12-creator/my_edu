# Rate Limit

You might say

I'm getting an error because I called the API too often. What does that limit mean?

**A service limit on requests, tokens, or concurrent tasks within a period of time**·After a limit is reached, a request may wait, slow down, or return 429. The exact limits vary by service, model, and account, so distinguish request, token, and concurrency limits.
