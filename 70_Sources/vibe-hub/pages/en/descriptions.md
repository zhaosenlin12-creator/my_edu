# Descriptions

You might say

On the details page, list the name, date, and status clearly, one field at a time.

**Show the field names and values of one record**·A description list pairs labels with read-only values for an order, account, or project. It may look similar to a form, but its main job is viewing. When people need to change the information, move them into a clearly editable form.
