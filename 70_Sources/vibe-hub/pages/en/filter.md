# Filter

You might say

Show only tasks due this week, incomplete, and assigned to me; hide the rest for now.

**Filtering is a feature that narrows the current content collection using existing properties or conditions.**·A task list can keep only items matching owner, status, and due date; a product list can narrow by price or size. Filtering excludes items that do not meet explicit conditions. It does not interpret a free-form sentence and is not the same as sorting results.
