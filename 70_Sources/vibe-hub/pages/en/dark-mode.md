# Dark Mode

You might say

Add real dark mode: text, borders, charts, and code blocks must switch with the page.

**Dark mode is a switchable dark interface theme state, not merely a page with a black background.**·When someone chooses dark mode or their system prefers it, backgrounds, text, borders, buttons, charts, and focus states need coordinated, sufficiently contrasting values. It serves different environments and preferences. A single dark poster or visual style is not automatically a switchable theme.
