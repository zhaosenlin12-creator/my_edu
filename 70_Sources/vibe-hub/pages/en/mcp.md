# Model Context Protocol

You might say

The AI needs to read my calendar and files. Isn't there a standard way to connect it to those?

**A protocol for connecting AI applications to external tools and sources such as calendars, files, and databases**·With a calendar MCP server connected, an agent can discover a schedule-search tool and request a lookup. The server returns the real schedule; MCP does not automatically grant calendar permission.
