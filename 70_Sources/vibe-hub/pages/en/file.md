File**≠**[Upload](/en/upload)

file displays a file that exists or is being processed. [Upload](/en/upload) covers the full flow of choosing, transferring, and processing a file.

### When to use it

- Uploaded attachments

  📄Project Plan.pdfPDF
- Project-file browsing
- Chat attachments

### When NOT to use it

- No file selected: use [Upload](/en/upload)

  📄Project Plan.pdfPDF
- An icon with no readable filename
- A hidden status or delete action
