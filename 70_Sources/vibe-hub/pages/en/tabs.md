# Tabs

You might say

There's too much content here. Split it into tabs so people can switch views with a click.

**Switch between a few peer sections on the same page**·Tabs work for sections such as Overview, Settings, and Logs under the same object. Keep the active tab obvious and decide whether unfinished input remains when switching. If the sections are really separate destinations, use navigation instead.
