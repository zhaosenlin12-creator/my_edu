# Anchor

You might say

This page is long. Add a small table of contents on the right that jumps to each section.

**Jump to a named section on the same long page**·Anchor navigation helps people scan and jump within documentation, policies, and other long pages. Keep section labels aligned with headings and update the active item as the page scrolls. It does not replace navigation between separate pages.

2. Scheme design

### When to use it

- Documentation table of contents

  BackgroundApproachRisksConclusion
- Long policy or report

  InstallQuick startAPIFAQ

  Scroll to “Quick start” and the table of contents highlights it automatically
- Single-page product site

  FeaturesPricingFAQ

  Click to smoothly scroll to the matching section
- A page with several clearly named sections

  Product featuresPricingCustomer reviewsFAQ

### When NOT to use it

- Use anchors for content on different pages
- List headings that do not exist

  HomePricing pageSign-in page

  These are other pages, so use links
- Cover the target heading with a sticky header

  Section 1Section 2Section 3

  Vague section labels don’t tell people what they lead to
- Add anchor navigation to a page too short to need it

  1.11.21.32.12.22.33.13.2

  The table of contents is longer than the page itself
