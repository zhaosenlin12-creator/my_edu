# Padding

You might say

The text is pressed right against the edge of the box. Add some breathing room inside it.

**Create space between a box and its content**·Padding adds room inside an element, between its border and its content. It affects the visible size and click area of buttons, cards, and panels. Keep repeated components on the same spacing scale so they feel related.

Know first

[Space](/en/space)

Content

### When to use it

- Give a button a comfortable click area
- Keep card content away from the edge

  Too smallAppropriate
- Create room inside a panel

  Spacing is too smallKeep padding
- Build consistent component sizes

### When NOT to use it

- Use padding to separate two independent components

  margin ↔ adds space outsidepadding ↔ adds space inside**Content**
- Shrink a control below a comfortable target size
- Use different inner spacing for identical items

  First lineSecond lineParagraph spacing should use line-height instead of increasing padding line by line.
- Add spaces to text instead of styling the container
