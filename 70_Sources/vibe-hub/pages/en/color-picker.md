# ColorPicker

You might say

Let people choose their own theme color instead of hard-coding one.

**A form control for viewing and choosing a color value**·Use a color picker for a theme, chart series, or drawing tool. Along with the palette, show a copyable value; text and icons still need enough contrast to be readable.

HEX   #7257D8

ColorPicker**≠**[Select](/en/select)

color-picker shows a color preview and an exact color value. [Select](/en/select) chooses from fixed text options.

### When to use it

- Theme or brand color

  Brand color
- Drawing and annotation tools
- Chart-series colors

### When NOT to use it

- Two clearly defined choices: use color swatch buttons

  Brand color
- Color as the only meaning: add text or an icon
- Low-contrast text with no stated contrast requirement
