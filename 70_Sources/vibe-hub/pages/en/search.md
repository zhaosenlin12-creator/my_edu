# Search

You might say

Add search above the project list so a name or keyword quickly finds potentially relevant projects.

**Search is a feature that uses a person's keywords to find potentially relevant results in a collection.**·After someone enters “budget,” projects whose name, description, or tags contain related words can appear; a help center can find articles by problem keywords too. Search answers what someone is looking for, usually ranking results by match or another rule. It does not merely narrow everything by a fixed condition.
