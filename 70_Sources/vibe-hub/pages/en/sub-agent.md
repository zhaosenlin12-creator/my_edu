# Sub-agent

You might say

Can I split a big task among a few helpers at the same time, then get one combined result?

**A separate agent the main agent assigns to a bounded part of a larger task**·Before release, a main agent can ask one sub-agent to review copy and another to check mobile layout, then combine their evidence. Each sub-agent needs a clear scope, permissions, and expected return.
