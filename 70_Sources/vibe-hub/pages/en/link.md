# Link

You might say

Make this text clickable so it takes people to another page.

**Click to open another page, location, or file**·A link takes people to another page, a place on the same page, or a downloadable file. Its text should make the destination clear, and keyboard users need a visible focus state. Use a [Button](/en/button) for actions such as saving or submitting.

### When NOT to use it

- Use a link to submit, save, or delete data

  you@example.com••••••••

  Sign inSign up
- Write only “click here” without naming the destination

  This week we launched three features: a new analytics dashboard, reports with custom filters, and redesigned member permissions.
- Style it like plain text so people miss it

  Want to learn about pricing? Click here; for customer stories, Click here.
- Open a new tab without a reason or a visible hint

  The new version is live; the release notes list every change.“Release notes” doesn’t look clickable, so the entry point is hard to spot
