# Top Nav

You might say

Use the classic layout: a navigation bar on top and all the content below it.

**Place the main navigation across the top of the page**·A top-navigation layout works when a product has a small number of primary sections and needs wide content space below. Keep labels short, show the current section, and decide how the navigation collapses on narrow screens.

Know first

[Navbar](/en/navbar)[Sticky](/en/sticky)

Content area*Set readable width according to content and screen*

### When to use it

- Marketing site

  ◆ logoProduct · Docs · PricingFree trial
- Product with a few main sections

  max-width: 1120px · margin: 0 auto
- Content that needs full page width

  Top bar · position: sticky
- Simple cross-page navigation

  Create project

### When NOT to use it

- Squeeze many deep sections into one row

  HomeProductApproachDocsBlogPricingAboutCareersEvents
- Hide the active destination
- Let navigation wrap into an accidental second line

  DashboardProjectsTasksFilesMembersCalendarReportsMessagesSettingsTrash
- Copy the desktop row unchanged onto a phone

  Top bar and body share the same background colorLacks visual layering

Anatomy

Content areaFooter · Copyright and secondary links

2MainThe page’s main content, centered with a maximum width and side whitespace

3FooterHolds copyright, regulatory information, and secondary links

Variants

Static

For a short page that does not need persistent navigation

Sticky

When navigation should remain available while users scroll through a long page

Stacked
