# Skill

You might say

I have to teach the AI the same process every time. Can it remember how to do this task?

**A structured folder—usually starting with `SKILL.md`—that gives an AI agent reusable instructions and supporting files**·A Skill can include instructions, scripts, references, and templates. When a task matches it, an agent reads those materials and follows the documented method.
