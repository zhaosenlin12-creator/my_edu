# Corner Feel

You might say

Make the corner rounding consistent across the site—some parts are square and some are round.

**Use corner shape to support the product's visual tone**·Sharp, softly rounded, and pill-shaped corners can make a page feel different, but the effect comes from consistent use across the system. Choose a small radius scale that fits control sizes and content instead of rounding every object the same way.

### When to use it

- Define a product-wide corner scale

### When NOT to use it

- Mix sharp, round, and pill shapes without a reason
- Use the same large radius on every box

  Evergreen Bank · Large transfer

  Transfer now

  A button outline that differs too much from other controls can weaken overall consistency.
- Let nested rounded corners collide

  Large-radius cardLarge-radius inputLarge-radius buttonUsing the same prominent radius at every level makes component roles harder to distinguish.
- Use corner shape as a substitute for information hierarchy

Anatomy

1SharpRadius is 0; works with border, weight, and spacing to create a stronger outline

2SubtleA smaller radius relative to component size, suitable for interface elements that need to retain a sense of edge

3MediumRadius is a higher proportion of size; check with component proportions and spacing

4PillThe radius is at least close to half the height, forming the shape of arcs at both ends

Variants

Sharp

When edges need to be clear or consistent with an existing right angle system

Subtle

When you need to preserve the edge while slightly softening the outline

Rounded

Component size allows for more pronounced arcs when coordinated with other roles in the system

Pill

When long labels or buttons require complete arcs at both ends
