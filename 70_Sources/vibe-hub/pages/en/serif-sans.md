# Serif & Sans

You might say

Use a serif font with a little character for the headings, then keep the body text clean and simple.

**Choose letterforms that match the content and reading task**·Serif typefaces have finishing strokes; sans-serif typefaces do not. Neither is automatically more readable or modern. Choose from the product's tone, text length, language support, and screen sizes, then test real headings and paragraphs.

**Good design holds up to a long look**

The same copy in a serif feels elegant and formal, like an editor's pick in a magazine.

Serif · Georgia / Songti

**Good design holds up to a long look**

The same copy in a sans feels modern and clean, like the interface of a productivity tool.

Sans · System default

### When to use it

- Set a clear tone for headings

  The character of designA serif display headline creates an editorial feel.
- Choose a comfortable body typeface

  Evergreen Private BankFinance and law firms: serif = trustworthy
- Pair two families with distinct roles

  Project nameOwnerUse sans-serif in interfaces: clean, efficient, and easy to scan.
- Test Chinese and Latin text together when both appear

  “Good design is as little design as possible.”Quotes can use a contrasting typeface, but it still needs to suit the language and context.

### When NOT to use it

- Choose a font only because of a style label

  This is a long body paragraph set in a small serif. At this screen size and weight, the letter details are not clear enough.
- Mix several families without clear roles

  Normal3 alerts

  Forcing an elegant tone onto an engineering tool creates a mismatch.
- Use a display face for long body text

  Vibe Design GuideWith only Georgia specified, Chinese falls back to the browser’s default serif.
