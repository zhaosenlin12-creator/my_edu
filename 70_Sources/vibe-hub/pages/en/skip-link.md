# SkipLink

You might say

Keyboard users have to press Tab too many times to reach the main content. Can they jump there directly?

**A link that lets keyboard users skip repeated navigation and move to the main content**·A skip link appears when someone starts tabbing through a page and moves focus past repeated header links to the main content. It is not ordinary navigation, and it needs a visible focus state and a working target.

SkipLink**≠**[Anchor](/en/anchor)

skip-link is a keyboard shortcut available when entering a page. [Anchor](/en/anchor) is an in-page table of contents that anyone can use.

### When to use it

- Long site header

  Skip to main contentKeyboard users see this first after pressing Tab
- Keyboard navigation
- Pages with repeated controls

### When NOT to use it

- Hiding it from keyboard focus

  Skip to main contentKeyboard users see this first after pressing Tab
- Linking to a missing or unclear target
- Using it to hide essential navigation
