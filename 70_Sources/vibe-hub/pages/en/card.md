# Card

You might say

Make each product a clickable card with the image on top and the name and price underneath.

**Keep information about one item in a single block**·A card usually groups an image, title, summary, and actions for the same object. It works well for browsing similar items. Make it clear whether the whole card is clickable; if only parts perform actions, keep links and buttons separate.
