# Tailwind CSS

You might say

Do I really have to open a separate CSS file for every style change? Can I adjust styles right where I write the markup?

**A utility-first CSS framework that styles elements through small class names**·Classes such as `p-6`, `rounded-xl`, and `border` give a card padding, rounded corners, and a border. Tailwind generates CSS rules; the same CSS layout rules still explain why something overlaps or crowds.
