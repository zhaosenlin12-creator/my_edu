# Result

You might say

After payment succeeds, show a clear success page instead of immediately sending people somewhere else.

**Explain the final outcome and the next available step**·A result page or panel marks the end of a task, such as payment success, submission failure, or an empty permission state. State what happened, what it means, and what the user can do next. Do not leave them at a decorative success or error icon.

### When NOT to use it

- Use a full result page for a tiny local action

  *✓*Nickname updatedOne changed word doesn’t need a whole page
- Show success before the server confirms it

  No data
- Report failure without a retry or support path
