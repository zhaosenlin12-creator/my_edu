# VibeHub 学习资料库

这是一个面向 Vibe Coding 学习和教学的资料库。

它的作用不是讲这个项目怎么制作出来的，而是帮助学生和老师更方便地理解、查找和复习 AI 编程相关概念。

## 这个项目有什么用

- 帮学生快速理解 Vibe Coding 里的常见术语
- 把零散概念按主题整理，方便系统复习
- 支持中文理解和英文表达对照
- 给老师备课、讲解概念、设计训练营内容提供参考
- 让学习资料可以在本地长期保存和反复检索

## 内容范围

资料主要围绕六类内容：

- AI
- 后端
- 设计
- Git
- 产品
- 通用技术

## 适合谁看

- 正在学习 AI 编程的学生
- 正在参加 Vibe Coding 训练的学员
- 需要补齐技术基础概念的人
- 需要给学生讲清楚技术词汇的老师

## 推荐读法

不要从头到尾硬读。

更适合按主题浏览，遇到不懂的词再搜索对应概念。

学习时可以先看中文解释，理解之后再对照英文表达。这样既能解决当前问题，也能慢慢建立自己的技术词汇库。
