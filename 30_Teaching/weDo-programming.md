# WeDo 编程启蒙

> 通过乐高 WeDo 2.0 + ScratchJr，把「写代码能动」变成真实可见。

## 学员画像
- 年龄：小低到小中
- 基础：图形化 + 命令行萌芽
- 班级人数：6-10 人

## 课节
1. 启动 WeDo 2.0 + ScratchJr
2. 体感编程：马达 / 声音 / 倾斜
3. 小项目：旋转木马 / 智能风扇 / 巡线小车
4. 复盘 + 评估：作品的 3 张图 + 1 段话

## 老师材料
- 教案：C:\教案\P1 几何王国 教案.docx（可复用）
- 教具：乐高 WeDo 2.0 套件

## 学员作品要求
- 至少 1 个可演示的可视化项目
- 1 段陈述：「我做的 / 我学的 / 我想怎么变」

## 风险与替代
- 设备联不上：准备 USB 直连代替蓝牙
- 学生不会：「双胞胎」结对 + 教师 shadow
