# Vibe Coding 入门 6 课时

> 小学四年级用 6 节课,理解 prompt + 跑通一个网页。

## 一句话

**不教 Python,只教"怎么用 Codex 跑通一个网页"**。孩子用 prompt 让 Codex 写代码,自己改改 prompt 让结果更好。

## 目标学生

- **学段**:小学四年级
- **基础**:会用浏览器、识字、能写一段话
- **总节数**:6 节(每节 1 小时)

## 教学目标

- [ ] 理解 prompt 是什么、怎么写
- [ ] 用 Codex / Vibe Coding 工具跑通一个网页
- [ ] 会改 prompt 让结果更好
- [ ] 上台讲自己的网页

## 每节结构

- **5 分钟**:复盘 + 目标
- **20 分钟**:核心概念 + 示范
- **20 分钟**:学员实作(在浏览器上跑)
- **5 分钟**:作品展示 + 评价

## 课节表

| 节 | 主题 | 学员成果 |
|---|---|---|
| 1 | Prompt 是什么 | 1 个能跑的小网页(生日卡) |
| 2 | 改 prompt 让结果变好 | 1 个不同样式的生日卡 |
| 3 | 加图片 + 加动效 | 1 个能分享的网页 |
| 4 | 写"我的介绍"网页 | 1 个个人主页 |
| 5 | 加表单 + 加交互 | 1 个能收数据的网页 |
| 6 | 上台讲自己的网页 | 1 段陈述 + 1 个可发布的 URL |

## 评价 / 交付物

- **可发布网页**:学员的网址 / GitHub Pages / Vercel
- **1 段陈述**:这 6 节我学到了什么
