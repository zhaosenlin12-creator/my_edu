# JrCode 编程进阶

> 把 Scratch 风格的积木代码衔接到 Python 真实代码，并初步建立物理和算法思维。

## 学员画像
- 年龄：小高到初一
- 基础：WeDo + Scratch 完成
- 班级人数：6-10

## 课节
1. 积木代码 → Python：变量 / 条件 / 循环 / 函数
2. 小项目：随机口令 / 抽奖器 / 弹跳小球
3. 海龟绘几 + 物理效果
4. 期末汇报：1 个可发布小项目
